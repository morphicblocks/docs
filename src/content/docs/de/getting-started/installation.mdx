<Aside type="note" title="Vor Version 1.0">
  Morphic Blocks ist veröffentlicht und einsatzbereit. Die Bibliothek ist noch
  vor Version 1.0, die öffentliche API kann sich daher zwischen Minor-Versionen
  ändern.
</Aside>

Morphic Blocks führt <a href="https://www.npmjs.com/package/blockly" target="_blank" rel="noopener noreferrer">Blockly</a> als
Dependency, es wird also automatisch mitinstalliert:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    <Code code={`npm install ${site.npmPackage}`} lang="sh" />
  </TabItem>
  <TabItem label="bun">
    <Code code={`bun add ${site.npmPackage}`} lang="sh" />
  </TabItem>
  <TabItem label="pnpm">
    <Code code={`pnpm add ${site.npmPackage}`} lang="sh" />
  </TabItem>
</Tabs>

## Optional: Pakete für den Code-Editor

Der Code-Editor, der Codespace und die Preview basieren auf CodeMirror 6. Die
CodeMirror-Pakete sind **optionale Peer-Dependencies** — installiere sie nur,
wenn du diese Views nutzt:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    <Code code={`npm install @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="bun">
    <Code code={`bun add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="pnpm">
    <Code code={`pnpm add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
</Tabs>

Sie werden verzögert geladen (lazy): Ein Projekt, das nie einen Code-Editor
einbindet, zahlt auch nicht dafür.

## Voraussetzungen

- Ein bundler-basiertes Setup (Vite oder alles, was modernes ESM auflöst). Die
  Bibliothek liefert ES-Module plus TypeScript-Deklarationen.
- TypeScript wird empfohlen — die öffentliche API ist vollständig typisiert —
  ist aber nicht erforderlich.
