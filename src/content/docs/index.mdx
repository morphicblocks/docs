Welcome to the **Morphic Blocks** documentation. Morphic Blocks is an
open-source TypeScript library built on Google Blockly that renders one block
model in multiple developer-defined **modes** — to support the gradual
transition between block-based and text-based programming. These docs cover how
to install it, define your blocks, and drive its views.

<CardGrid>
	<Card title="One block model, many modes" icon="puzzle">
		Define blocks once and render them as icons, blocks, or source text —
		modes are fully developer-defined.
	</Card>
	<Card title="Gradual block-to-text transition" icon="pencil">
		Move learners from block-based to text-based programming step by step,
		without switching tools.
	</Card>
	<Card title="Bring your own UI" icon="setting">
		An embeddable library, not an app: headless components you can style and
		arrange freely.
	</Card>
	<Card title="Built on Blockly" icon="open-book">
		The proven Google Blockly engine stays authoritative underneath — with
		morphic rendering on top.
	</Card>
</CardGrid>
