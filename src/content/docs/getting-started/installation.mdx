Morphic Blocks lists <a href="https://www.npmjs.com/package/blockly" target="_blank" rel="noopener noreferrer">Blockly</a> as a
dependency, so it is installed for you:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    <Code code={`npm install ${site.npmPackage}`} lang="sh" />
  </TabItem>
  <TabItem label="bun">
    <Code code={`bun add ${site.npmPackage}`} lang="sh" />
  </TabItem>
  <TabItem label="pnpm">
    <Code code={`pnpm add ${site.npmPackage}`} lang="sh" />
  </TabItem>
</Tabs>

<Aside type="tip" title="pnpm and brand new versions">
  Recent pnpm versions refuse a package version during its first day on npm
  (the minimum release age). Right after a Morphic Blocks release,
  `pnpm add` can therefore fail with `ERR_PNPM_MINIMUM_RELEASE_AGE_VIOLATION`.
  Wait a day, or allow that one version in `pnpm-workspace.yaml`:

  ```yaml
  minimumReleaseAgeExclude:
    - morphic-blocks@0.3.0
  ```
</Aside>

## Blockly's media

Blockly's images and sounds load from `blockly-media/` next to your page. The
bundler plugin that comes with the package copies them there when `dev` or
`build` starts:

```ts
// vite.config.ts (also morphic-blocks/webpack, /rspack, /rollup, /esbuild)
import blocklyMedia from "morphic-blocks/vite";

export default { plugins: [blocklyMedia()] };
```

With Parcel, Turbopack or no bundler, run `morphic-blocks copy-media
public/blockly-media` before `dev` and `build` instead. See
[Privacy & External Requests](/guides/privacy/) for other folders and servers.

## Optional: code editor packages

The code editor and the codespaces are built on CodeMirror 6. The
CodeMirror packages are **optional peer dependencies** — install them only if
you use those views:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    <Code code={`npm install @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="bun">
    <Code code={`bun add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="pnpm">
    <Code code={`pnpm add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
</Tabs>

They are loaded lazily: a project that never mounts a code editor never pays
for them.

`@codemirror/lang-javascript` is needed only for the code editor, which shows
the JavaScript generated from the blocks, useful for testing and debugging.
Codespaces show your own languages and work without it.

## Requirements

- A bundler-based setup (Vite, or anything that resolves modern ESM). The
  library ships ES modules plus TypeScript declarations.
- TypeScript is recommended — the public API is fully typed — but not required.
