Morphic Blocks needs [Blockly](https://www.npmjs.com/package/blockly) as a peer dependency:

<Tabs syncKey="pkg">
  <TabItem label="npm">

  <TabItem label="bun">

  <TabItem label="pnpm">
    <Code code={`pnpm add ${site.npmPackage} blockly`} lang="sh" />
  </TabItem>
</Tabs>

## Optional: code editor packages

The code editor, codespace, and preview views are built on CodeMirror 6. The
CodeMirror packages are **optional peer dependencies** — install them only if
you use those views:

<Tabs syncKey="pkg">
  <TabItem label="npm">
    <Code code={`npm install @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="bun">
    <Code code={`bun add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
  <TabItem label="pnpm">
    <Code code={`pnpm add @codemirror/state @codemirror/view @codemirror/lang-javascript`} lang="sh" />
  </TabItem>
</Tabs>

They are loaded lazily: a project that never mounts a code editor never pays
for them.

## Requirements

- A bundler-based setup (Vite, or anything that resolves modern ESM). The
  library ships ES modules plus TypeScript declarations.
- TypeScript is recommended — the public API is fully typed — but not required.
