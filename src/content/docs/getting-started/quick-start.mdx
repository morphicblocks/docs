This walkthrough builds the smallest useful setup: one block, two modes, a
toolbox, and a workspace — with a runtime mode switch at the end.

<Steps>

1. **Define your blocks** in a definitions JSON. A block declares named
   *elements* (its visual parts); the global `elementTypes` registry says what
   each element name is; *modes* pick which elements are shown.

   ```json
   // definitions.json
   {
     "elementTypes": {
       "title":      "text",
       "conceptual": "code",
       "python":     "code"
     },
     "modes": [
       { "name": "conceptual", "elements": ["title", "conceptual"] },
       { "name": "python",     "elements": ["title", "python"] }
     ],
     "categories": [
       { "name": "Output", "color": "#5C81A6" }
     ],
     "blocks": [
       {
         "identifier": "text_print",
         "category": "Output",
         "elements": {
           "title":      "Print",
           "conceptual": "Output %1",
           "python":     "print(%1)"
         },
         "inputSlots": {
           "1": { "kind": "value", "name": "TEXT" }
         }
       }
     ]
   }
   ```

   `%1` is an input slot — it becomes a Blockly input on the block and a
   substitution point in text renderings.

2. **Write a behavior** for the block. Behaviors generate the executable
   JavaScript, one function per block identifier:

   ```ts
   // behaviors.ts
   import type { MorphicBehaviorMap } from "morphic-blocks";

   export const behaviors: MorphicBehaviorMap = {
     text_print(proxy) {
       return `console.log(${proxy.inputs.TEXT ?? "undefined"});\n`;
     },
   };
   ```

3. **Add containers** to your page:

   ```html
   <div id="toolbox"></div>
   <div id="workspace"></div>
   ```

4. **Mount the engine:**

   <Code
     lang="ts"
     title="main.ts"
     code={`import { MorphicBlocks } from "${site.npmPackage}";
import definitions from "./definitions.json";
import { behaviors } from "./behaviors";

// The constructor takes the whole definitions file plus your behaviors.
// mount() and mountToolbox() inherit its modes / presets / highlighting /
// categories, so a call only carries runtime concerns.
const engine = new MorphicBlocks(definitions, behaviors);

engine.mount({
  workspaceContainer: document.getElementById("workspace")!,
  // No presets here, so the first mode ("conceptual") is used.
});

engine.mountToolbox(document.getElementById("toolbox")!);`}
   />

   Drag the *Print* tile from the toolbox into the workspace — it creates a
   real Blockly block.

5. **Switch modes at runtime.** The same blocks re-render with the `python`
   element as their template:

   ```ts
   engine.setModes({ workspaceMode: "python", toolboxMode: "python" });
   ```

6. **Generate code** from the workspace via your behaviors:

   ```ts
   const js = engine.generateJavaScript();
   ```

</Steps>
